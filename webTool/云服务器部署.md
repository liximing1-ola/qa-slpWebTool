### 1.安装 gunicorn,nginx
`pip install gunicorn`
`nginx`一般都已经安装了,忽略
### 2.修改nginx配置,重启nginx
- `vim /etc/nginx/conf.d/http.conf` 路径可能不同和开发对接
- 新增nginx配置,一般是配置在监听80端口的转发下
```
location /qatest2023/ {
        proxy_pass http://127.0.0.1:2020/qatest2023/;
    }
```
- 检查`nginx -t`
检查后结果为如下,则表示正确
```
nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
nginx: configuration file /etc/nginx/nginx.conf test is successful
```

- 重启`nginx -s reload`
### 4.修改代码配置,保持和nginx一致
- 需要修改43个地方,一定要个nginx中保持一致
- 1.`conMysql.py`中的数据库配置
- 2.`*.html`中的`href`的路径
- 3.`main.py`中的`base_path`的路径
### 4.使用配置文件,启动gunicorn,运行web
`gunicorn -c gunicorn_config.py main:app`
`gunicorn -c gunicorn_config.py app:app`
