## 一、前置准备

### 1.1 服务器要求
| 项目 | 要求 |
|------|------|
| 操作系统 | CentOS 7+ / Ubuntu 18.04+ / Debian 10+ |
| Python | 3.8 及以上 |
| 内存 | 最低 1GB，推荐 2GB+ |
| 磁盘 | 最低 5GB 可用空间 |
| 端口 | 80（Nginx）、2023（Gunicorn，仅内部访问） |

### 1.2 需要确认的信息
在部署前，请先确认以下配置信息：
- [ ] 云服务器公网 IP
- [ ] 数据库地址（IP / 域名）
- [ ] 数据库端口（默认 3306）
- [ ] 数据库用户名和密码
- [ ] 数据库名称（默认 `xianshi`）

### 1.3 上传代码到服务器
```bash
# 方式一：使用 scp 上传（本地执行）
scp -r webTool/* root@<服务器IP>:/opt/qatest2023/

# 方式二：使用 git 拉取（服务器执行）
cd /opt/qatest2023
git clone <你的仓库地址> .
```

## 三、手动部署步骤

> 如果一键脚本有问题，可以按以下步骤手动操作。

### 3.1 安装系统依赖

**CentOS / RHEL:**
```bash
yum update -y
yum install -y epel-release
yum install -y python3 python3-pip python3-devel nginx gcc
```

**Ubuntu / Debian:**
```bash
apt-get update
apt-get install -y python3 python3-pip python3-venv python3-dev nginx gcc
```

### 3.2 创建 Python 虚拟环境

**方式一：使用 venv（推荐）**
```bash
cd /opt/qatest2023
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

**方式二：使用 conda**
```bash
# 安装 Miniconda（如未安装）
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# 创建环境
conda create -n testenv python=3.9 -y
conda activate testenv
pip install -r requirements.txt
```

### 3.3 配置环境变量
```bash
cd /opt/qatest2023
cp .env.example .env
vim .env
```

修改以下关键配置：
```ini
FLASK_ENV=production
FLASK_DEBUG=False

# 数据库配置（务必修改为实际地址）
DB_HOST=你的数据库IP
DB_PORT=3306
DB_USER=你的数据库用户名
DB_PASSWORD=你的数据库密码
DB_NAME=xianshi
```

### 3.4 创建日志目录
```bash
mkdir -p /opt/qatest2023/log
```

### 3.5 测试启动
```bash
cd /opt/qatest2023
source venv/bin/activate   # 或 conda activate testenv
export $(cat .env | xargs)
gunicorn -c gunicorn_config.py app:app
```

验证启动：
```bash
# 检查进程
ps -ef | grep gunicorn

# 检查端口
ss -tlnp | grep 2023

# 测试访问
curl http://127.0.0.1:2023/qatest2023/
```

### 3.6 配置 Nginx

编辑 Nginx 配置文件：
```bash
vim /etc/nginx/conf.d/http.conf
```

在监听 80 端口的 server 块中添加：
```nginx
# ===== QA测试工具平台 =====
location /qatest2023/ {
    proxy_pass http://127.0.0.1:2023/qatest2023/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_connect_timeout 60s;
    proxy_read_timeout 120s;
}
```

检查并重载：
```bash
nginx -t
nginx -s reload
```

### 3.7 配置 Systemd 服务

创建服务文件：
```bash
vim /etc/systemd/system/qatest2023.service
```

写入以下内容（注意修改路径）：
```ini
[Unit]
Description=QA Test Tool Platform - Gunicorn
After=network.target

[Service]
Type=notify
User=root
Group=root
WorkingDirectory=/opt/qatest2023
EnvironmentFile=/opt/qatest2023/.env
ExecStart=/opt/qatest2023/venv/bin/gunicorn -c gunicorn_config.py app:app
ExecReload=/bin/kill -s HUP $MAINPID
Restart=on-failure
RestartSec=5
KillMode=mixed
TimeoutStopSec=10
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
systemctl daemon-reload
systemctl enable qatest2023    # 开机自启
systemctl start qatest2023     # 启动服务
systemctl status qatest2023    # 查看状态
```

## 四、配置说明

### 4.1 需要保持一致的配置项

以下配置项需要互相同步，**务必保持一致**：

| 配置文件 | 配置项 | 默认值 | 说明 |
|---------|--------|--------|------|
| `config.py` | `BASE_PATH` | `/qatest2023` | 应用基础路径 |
| `gunicorn_config.py` | `bind` | `127.0.0.1:2023` | Gunicorn 监听地址 |
| Nginx 配置 | `proxy_pass` | `http://127.0.0.1:2023` | 反向代理目标 |
| Nginx 配置 | `location` | `/qatest2023/` | URL 路径 |
| `.env` | `DB_HOST` 等 | - | 数据库连接信息 |
| HTML 模板 | `href` 路径 | `/qatest2023/...` | 页面内链接 |

### 4.2 Gunicorn 配置说明

`gunicorn_config.py` 关键参数：
```python
bind = "127.0.0.1:2023"      # 绑定地址（仅内部访问）
workers = 2                   # 工作进程数（建议 CPU 核数 * 2 + 1）
worker_class = 'gevent'       # 工作模式（协程）
daemon = True                 # 守护进程模式
loglevel = 'debug'            # 日志级别（生产建议 warning）
```

## 五、常用运维命令

### 5.1 服务管理
```bash
# 启动
systemctl start qatest2023

# 停止
systemctl stop qatest2023

# 重启
systemctl restart qatest2023

# 查看状态
systemctl status qatest2023

# 查看日志
journalctl -u qatest2023 -f
```

### 5.2 Gunicorn 管理
```bash
# 查看进程
ps -ef | grep gunicorn

# 杀死所有 gunicorn 进程
kill -9 $(ps -ef | grep gunicorn | grep -v grep | awk '{print $2}')

# 手动启动（调试用）
cd /opt/qatest2023
source venv/bin/activate
gunicorn -c gunicorn_config.py app:app
```

### 5.3 Nginx 管理
```bash
# 检查配置
nginx -t

# 重载配置
nginx -s reload

# 查看状态
systemctl status nginx

# 查看错误日志
tail -f /var/log/nginx/error.log
```

### 5.4 快速检查
```bash
# 检查端口监听
ss -tlnp | grep -E '80|2023'

# 检查进程
ps aux | grep -E 'nginx|gunicorn'

# 测试接口
curl http://127.0.0.1:2023/qatest2023/
curl http://<服务器IP>/qatest2023/
```

## 六、常见问题排查

### Q1: 访问返回 502 Bad Gateway
**原因**: Gunicorn 未启动或端口不对  
**排查**:
```bash
# 1. 检查 gunicorn 是否运行
ps -ef | grep gunicorn

# 2. 检查端口
ss -tlnp | grep 2023

# 3. 查看 gunicorn 错误日志
cat /opt/qatest2023/log/debug.log
```

### Q2: 访问返回 404 Not Found
**原因**: Nginx 路径配置不匹配  
**排查**:
```bash
# 1. 检查 nginx 配置中的 location 路径
cat /etc/nginx/conf.d/http.conf | grep qatest2023

# 2. 确认 config.py 中 BASE_PATH 与 nginx location 一致
grep BASE_PATH /opt/qatest2023/config.py
```

### Q3: 数据库连接失败
**排查**:
```bash
# 1. 测试数据库连通性
mysql -h <数据库IP> -u <用户名> -p -e "SELECT 1"

# 2. 检查 .env 配置
cat /opt/qatest2023/.env | grep DB_

# 3. 检查防火墙
telnet <数据库IP> 3306
```

### Q4: 页面内链接跳转 404
**原因**: HTML 模板中的 `href` 路径与 `BASE_PATH` 不一致  
**解决**: 确保所有模板中的链接前缀为 `/qatest2023/`（与 `config.py` 中 `BASE_PATH` 一致）

### Q5: 修改代码后不生效
```bash
# 重启 gunicorn 服务
systemctl restart qatest2023

# 或杀死后重新启动
kill -9 $(ps -ef | grep gunicorn | grep -v grep | awk '{print $2}')
systemctl start qatest2023
```
